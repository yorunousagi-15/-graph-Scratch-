# MathLab V10

できるだけ多くの種類の数学グラフを、シンプルなJavaScriptで描画するサイトです。

## 対応
- 通常の関数 y=f(x)
- 複数関数の同時描画
- 三角関数・逆三角関数
- 指数・対数
- べき関数
- 絶対値・床関数・天井関数
- 階乗・ガンマ関数
- 極座標
- 媒介変数
- 陰関数
- 複素平面
- ガンマ関数、ゼータ関数、erf、Bessel J0/J1、sinc
- ダークモード

V10ではPlotlyやmath.jsを使わず、CanvasとJavaScriptだけで描画しています。
GitHub Pagesでは4ファイルをリポジトリ直下に置くだけで動作します。

注意：特殊関数や複素関数は数値近似です。厳密計算・証明システムではありません。
