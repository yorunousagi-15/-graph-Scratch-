# MathLab V7

学校PCなどで表示しやすいよう、Plotlyのロゴを非表示にした数学グラファーです。

## 主な機能
- 実関数・複数関数
- tan(x) を含む三角関数の描画
- 微分、定積分、絶対値積分、零点候補探索
- Gamma Γ(x)、Zeta ζ(x)、Digamma、Polygamma
- erf、Bessel J0、sinc、log Gamma
- 複素平面 f(z)、Γ(z)、ζ(z)
- 臨界線 s=1/2+it の |ζ(s)|
- 複素積分 ∮f(z)dz と留数総和の数値推定
- 極座標・媒介変数
- ダークモード

## GitHub Pages
`index.html`, `style.css`, `script.js`, `README.md` をリポジトリ直下へアップロードし、Settings → Pages → `main` → `/ (root)`。

## 注意
特殊関数・ζ関数・Γ関数・複素積分は数値近似です。数学的証明用ではありません。
